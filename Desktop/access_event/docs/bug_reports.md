# Баг-репорты AccessEvent

## BUG-01. [Major] Повторная регистрация с тем же email возвращает 500
- Серьёзность: Major
- Приоритет: P2
- Шаги воспроизведения:
  1. POST /api/register с email test@mail.ru
  2. POST /api/register ещё раз с тем же email
- Фактический результат: 500 Internal Server Error (нарушение UNIQUE(email))
- Ожидаемый результат: 400 с понятным сообщением
- Статус: Исправлен — в routes/auth.py добавлена проверка существования email и username до записи в БД

## BUG-02. [Major] Регистрация принимает email без @
- Серьёзность: Major
- Приоритет: P2
- Шаги воспроизведения:
  1. POST /api/register с email "not-an-email"
- Фактический результат: 201, пользователь создан
- Ожидаемый результат: 400, сообщение о неверном формате
- Статус: Исправлен — добавлена валидация формата email

## BUG-03. [Minor] Тесты на SQLite не проверяют CHECK-ограничение статуса регистрации
- Серьёзность: Minor
- Приоритет: P3
- Шаги воспроизведения:
  1. В тестовой БД (SQLite) создать Registration со статусом "wrong"
  2. Выполнить commit
- Фактический результат: commit проходит без ошибки, ограничение ck_registration_status не срабатывает
- Ожидаемый результат: ошибка ограничения, как в PostgreSQL
- Статус: Не исправлен — SQLite не поддерживает проверку CHECK; перенос тестов на PostgreSQL запланирован на следующий этап
